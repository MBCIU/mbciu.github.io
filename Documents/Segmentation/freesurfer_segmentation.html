FreeSurfer cortical segmentation

Cross-sectional reconstruction, 7T considerations, quality control and statistics

MBCIU practical tutorial
Scope. This workflow is intended for research-quality T1-weighted structural MRI. Every reconstruction must pass visual QC before morphometric measures are analysed.

1. Prerequisites

  • FreeSurfer 8.1.0 (the current MBCIU workflow version) and a valid FreeSurfer licence.
  • A bias-corrected, research-quality T1-weighted NIfTI image.
  • A writable output directory with sufficient quota; a full reconstruction produces thousands of files.
  • For cluster processing: 8 CPUs, at least 16 GB RAM, and up to 24–36 hours per subject.
# Example environment setup — adapt the module name to your cluster
module load FreeSurfer/8.1.0-rocky8_x86_64
export FS_LICENSE=/path/to/license.txt
export SUBJECTS_DIR=/path/to/reconall_xsection
mkdir -p "$SUBJECTS_DIR"

recon-all -version
test -r "$FS_LICENSE" && echo "Licence found"

2. Check the input before processing

  1. Confirm the image belongs to the intended participant and time point.
  2. Check orientation, coverage, motion, ringing, wrap-around and intensity artefacts in Freeview or another NIfTI viewer.
  3. Confirm that the image is T1-weighted and has not already been skull stripped.
  4. Record the input checksum and software version for provenance.
INPUT=/path/to/sub-001_T1w.nii.gz
SUBJECT_ID=sub-001

test -s "$INPUT" || { echo "Missing input: $INPUT"; exit 1; }
mri_info --dim "$INPUT"
mri_info --res "$INPUT"
sha256sum "$INPUT"
Do not proceed if the anatomy is cropped, severely motion-corrupted, incorrectly oriented, or contains a non-brain field-of-view that invalidates reconstruction.

3. Run a cross-sectional reconstruction

The standard command imports the input and executes the complete cortical reconstruction and volumetric segmentation stream:

recon-all \
  -subject "$SUBJECT_ID" \
  -i "$INPUT" \
  -all \
  -parallel \
  -openmp 8

Use -i only when creating the subject directory. To resume an interrupted run, omit -i:

recon-all -subject "$SUBJECT_ID" -all -parallel -openmp 8

Monitor progress without modifying the output:

tail -f "$SUBJECTS_DIR/$SUBJECT_ID/scripts/recon-all.log"
grep -E "finished without error|exited with ERRORS" \
  "$SUBJECTS_DIR/$SUBJECT_ID/scripts/recon-all.log"

4. 7T and submillimetre data

7T MPRAGE and MEMP2RAGE data can have stronger intensity inhomogeneity than typical 3T inputs. Inspect the bias field and tissue contrast carefully before reconstruction. Do not assume that higher spatial resolution guarantees a better segmentation.

For native submillimetre reconstruction, include -hires. Current FreeSurfer release guidance still requires this flag for inputs below 1 mm isotropic:

recon-all \
  -subject "$SUBJECT_ID" \
  -i "$INPUT" \
  -all -hires \
  -parallel -openmp 8
Choose deliberately. Native high-resolution processing uses more memory and time. Keep the choice consistent across the cohort and record it in the analysis protocol. For MEMP2RAGE, evaluate the chosen reconstruction (for example, uniform/denoised T1-weighted image) before committing the whole cohort.

6. Visual quality control

Open the anatomical volume, segmentation and both surfaces together:

freeview \
  -v "$SUBJECTS_DIR/$SUBJECT_ID/mri/T1.mgz" \
     "$SUBJECTS_DIR/$SUBJECT_ID/mri/aseg.mgz":colormap=lut:opacity=0.35 \
  -f "$SUBJECTS_DIR/$SUBJECT_ID/surf/lh.white":edgecolor=blue \
     "$SUBJECTS_DIR/$SUBJECT_ID/surf/lh.pial":edgecolor=red \
     "$SUBJECTS_DIR/$SUBJECT_ID/surf/rh.white":edgecolor=blue \
     "$SUBJECTS_DIR/$SUBJECT_ID/surf/rh.pial":edgecolor=red

Inspect systematically in all three planes

  • Skull strip: brain tissue retained; dura, skull and neck excluded.
  • White surface: follows the white/grey boundary without cutting through gyri.
  • Pial surface: follows the grey/CSF boundary without including dura or vessels.
  • Subcortical labels: plausible ventricles, thalamus, caudate, putamen, pallidum, hippocampus and amygdala.
  • Temporal poles, orbitofrontal cortex, insula and superior cortex: common failure locations.
  • Left–right symmetry and unexpected regional outliers.
Minimum evidence: retain completion status, visual QC outcome, reviewer, date, software version, input identifier and notes on any correction.

7. Extract cohort statistics

Once every included subject has passed QC, create analysis-ready tables:

# One row per subject; subcortical volumes
asegstats2table \
  --subjects sub-001 sub-002 sub-003 \
  --stats aseg.stats \
  --tablefile aseg_volumes.tsv

# Desikan–Killiany cortical thickness
aparcstats2table \
  --subjects sub-001 sub-002 sub-003 \
  --hemi lh --meas thickness \
  --tablefile lh_aparc_thickness.tsv

aparcstats2table \
  --subjects sub-001 sub-002 sub-003 \
  --hemi rh --meas thickness \
  --tablefile rh_aparc_thickness.tsv

Do not silently mix FreeSurfer versions, processing flags, corrected and uncorrected outputs, or scans that failed QC.

Interrupted jobscripts/recon-all.logrecon-all -s ID -all without -i
Preserve provenance. Back up the original reconstruction or use a versioned output location before manual correction. Never overwrite a completed cohort without recording what changed.

9. Reusable SLURM workflow

Download the companion script, adapt the module/licence paths, and submit one subject per job:

Download freesurfer_reconall_slurm.sh

sbatch freesurfer_reconall_slurm.sh \
  sub-001 \
  /path/to/sub-001_T1w.nii.gz \
  /path/to/reconall_xsection

# Native submillimetre processing
sbatch --export=ALL,HIRES=1 freesurfer_reconall_slurm.sh \
  sub-001 /path/to/sub-001_T1w.nii.gz /path/to/reconall_xsection

10. Completion checklist

  • ☐ Input identity, orientation, coverage and quality confirmed
  • ☐ FreeSurfer version and command recorded
  • ☐ recon-all.log reports successful completion
  • ☐ Skull strip, aseg, white and pial surfaces inspected in three planes
  • ☐ QC status and reviewer recorded
  • ☐ Corrections and reruns documented
  • ☐ Only QC-passed subjects included in exported tables
