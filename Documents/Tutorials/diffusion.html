Diffusion MRI preprocessing

MRtrix3, phase-encoding checks and tensor measures

Research training guide · Updated 14 October 2026. Examples use placeholder paths and require adaptation to your acquisition and installed software. Test one participant before scaling to a cohort.

1. Verify inputs

You need DWI volumes, their matching b-values and b-vectors, and acquisition metadata. Confirm gradient counts match the image volumes. Check phase-encoding direction and total readout time from metadata rather than folder names. If using reverse-encoding b=0 images, verify matching geometry, readout and opposite encoding.

2. Import and inspect

mrconvert dwi.nii.gz dwi.mif -fslgrad dwi.bvec dwi.bval -json_import dwi.json
mrinfo dwi.mif
mrview dwi.mif

Check coverage, orientation, gross motion and slice dropout. Inspect gradient directions with the appropriate MRtrix tools before model fitting.

3. Correct the data

Denoise before interpolation; apply Gibbs-ringing correction only when appropriate to the acquisition, particularly considering partial Fourier. The example below assumes a validated, matched AP/PA b=0 pair, AP DWI, and full-Fourier data. Replace the readout placeholder with seconds from acquisition metadata.

dwidenoise dwi.mif dwi_den.mif -noise noise.mif
mrdegibbs dwi_den.mif dwi_degibbs.mif
# b0_AP.mif and b0_PA.mif are matched calibration images
mrcat b0_AP.mif b0_PA.mif b0_pair.mif -axis 3
dwifslpreproc dwi_degibbs.mif dwi_preproc.mif \
  -rpe_pair -se_epi b0_pair.mif -pe_dir AP \
  -readout_time READOUT_SECONDS -eddy_options " --repol"

If no reverse-encoding data exist, choose the documented alternative deliberately and record the absence of susceptibility correction.

4. Tensor measures and QC

dwi2mask dwi_preproc.mif mask.mif
dwi2tensor dwi_preproc.mif tensor.mif -mask mask.mif
tensor2metric tensor.mif -fa fa.mif -adc md.mif

Check corrected b=0 anatomy, mask boundaries, motion, eddy outliers and gradient orientation. Review FA/MD maps for implausible patterns and registration before extracting tract means. These commands illustrate tensor fitting, not a complete tractography or connectome pipeline. For multi-shell acquisitions, specify and justify which shells enter the tensor model.
