Longitudinal hippocampal QC

Within-participant processing, visual review and missing-data tracking

Research training guide · Updated 14 October 2026. Examples use placeholder paths and require adaptation to your acquisition and installed software. Test one participant before scaling to a cohort.

1. Build a longitudinal manifest

Record participant, visit, acquisition date, input path and expected output directory. Verify each visit independently. Separate missing raw inputs, failed processing, missing output files and QC exclusions. Never substitute zero for an unavailable volume.

2. Run the longitudinal stream

Complete and inspect cross-sectional reconstructions first. Build the within-participant template, then process each visit using that template. These commands illustrate the reconstruction sequence; hippocampal subfield segmentation is a separate step using tools appropriate to your pinned FreeSurfer release.

recon-all -base sub-001_base -tp sub-001_ses-01 -tp sub-001_ses-02 -all
recon-all -long sub-001_ses-01 sub-001_base -all
recon-all -long sub-001_ses-02 sub-001_base -all

Maintain the same FreeSurfer version and subfield atlas across visits. Confirm actual output names rather than assuming a v21/v22 filename from another release.

3. Inspect the label maps

Review anatomical images and subfield overlays in all three planes, covering head, body and tail on both sides. Use Freeview or another viewer/gallery that preserves alignment and label colours. Retain screenshots and reviewer decisions. A gallery must cover the full hippocampus; one selected slice cannot establish a pass.

Check boundaries, holes, implausible labels, adjacent CSF inclusion and consistency across visits. Review the original anatomy alongside the labels when an overlay is ambiguous.

4. Screen cohort measurements

Plot volumes by region, hemisphere and visit. Flag extreme values, asymmetry and unexpected within-participant change for visual review. Use the exact ENIGMA protocol selected for the study if claiming ENIGMA compliance; a generic z-score screen alone is not an ENIGMA assessment.

Statistical flags trigger review and do not automatically justify exclusion. Record the chosen thresholds, reference population, visual outcome and final inclusion decision.

5. Resolve missing data

Join extracted measurements to the expected manifest using participant and visit identifiers. Check job state, logs and expected outputs for every unmatched row. Increase wall time only when logs or scheduler accounting show a timeout; investigate memory, input or anatomical failures separately. Keep rerun attempts and their QC outcomes traceable.
